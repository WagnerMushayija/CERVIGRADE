# CerviGrade

AI-assisted cervical cancer screening support tool. Grades Pap-smear field
images by the most serious cervical cell abnormality found. A YOLO11n detector
finds the cells in each photo, an EfficientNetB0 classifier grades every cell,
and a clinician confirms or corrects each result.

## Folder layout

- `data/raw/` - datasets exactly as downloaded (CRIC, SIPaKMeD, Mendeley).
  Not tracked in git - too large, and anyone can re-download them.
- `data/processed/` - cropped/resized/stain-normalized images, ready for
  training. Also not tracked in git - regenerated by the preprocessing
  scripts, not hand-edited.
- `notebooks/` - exploratory analysis and one-off experiments.
- `src/preprocessing/` - dataset download and preprocessing scripts.
- `src/training/` - fine-tuning scripts for each model architecture.
- `src/evaluation/` - model comparison, metrics, Grad-CAM.
- `src/app/` - the working app: `backend/` (FastAPI) and `frontend/` (HTML, CSS and
  JavaScript modules). Loads the trained weights from `models/`. See "How the app code
  is organised" below.
- `models/` - saved trained weights. Not tracked in git - large binaries,
  regenerated by re-running training.
- `docs/` - the capstone proposal, literature review docs, and
  presentation materials.

## How the app code is organised

Backend (`src/app/backend/`), one job per file, with classes for the parts that hold state:

- `classifiers.py`: `Classifier` (the rulebook) with `EfficientNetClassifier` (the real model, with
  Grad-CAM) and `StubClassifier` (a placeholder). The rest of the app does not care which one it uses.
- `pipeline.py`: `CellDetector` (YOLO) and `FieldPipeline` (detector + classifier, the photo verdict).
- `institution.py`: `InstitutionPolicy`, the "only @alustudent.com" rule.
- `security.py`: `PasswordHasher` and `TokenService`.
- `users.py`: `UserRepository`, all database work for accounts.
- `db.py`, `records.py`, `model.py`, `gradcam.py`, `manage.py`, `main.py`: storage, response building,
  grading vocabulary, heat-map drawing, admin commands, and the API endpoints.
- `tests/`: automated tests (`python -m pytest tests -q`, no model weights needed).

Frontend (`src/app/frontend/`): `index.html` is the markup only. `css/styles.css` is the look.
`js/` is plain JavaScript modules: `App.js` builds the shared parts; `core/` has `ApiClient`,
`Session`, `Router`, `Toast`, `Lightbox` and helpers; `components/` has `FieldViewer`, `CamPanel`,
`Navbar` and `GradingProgress`; `pages/` has one class per screen, all extending `Page`.

How the data, database and endpoints fit together: `docs/How_CerviGrade_Works.md`.

## Technical requirements

- Python 3.11 was used for testing (TensorFlow 2.17 supports 3.9 to 3.12).
- `src/app/backend/requirements.txt`: FastAPI 0.115, TensorFlow 2.17, PyTorch and Ultralytics (the detector),
  OpenCV (headless), PyJWT. About 2 GB of free memory while grading a photo.
- The two model files in `models/`: `efficientnetb0_cric_retrained.keras` (17 MB) and
  `stage2_severity_oversampled_best.pt` (5 MB). Without them the app falls back to a labelled placeholder.
- A current browser (Chrome, Edge or Firefox). The page is served by the backend, so open it at
  http://localhost:8000 rather than double-clicking the HTML file.

## Running the app

    cd src/app/backend
    pip install -r requirements.txt
    uvicorn main:app --reload --port 8000

The first time it starts, it creates one admin account and prints its email
(`admin@alustudent.com`) and a random password in the terminal. Copy the password then, because
it is shown once. Open http://localhost:8000 in a browser, sign in, and
add technicians and clinicians under Users. There is no public sign-up, and only
`@alustudent.com` addresses are accepted, both when an account is added and when someone signs in.
Accounts made before this rule (`admin`, `tech1`) get the domain added to their name on the next start.
Swagger UI is at http://localhost:8000/docs.

The technician uploads microscope field photos. A YOLO detector (`models/stage2_severity_oversampled_best.pt`)
boxes the cells, the retrained EfficientNetB0 (`models/efficientnetb0_cric_retrained.keras`) grades each one, and the
photo's result is the most serious grade among cells the model is at least 90% sure of. The page draws the boxes;
click one to see how that cell was graded. A full photo takes a few minutes on a laptop CPU (about 3 minutes on the author's laptop; the time is printed in the terminal for each photo).

Three roles: a lab technician uploads a patient's slide images, a clinician
confirms or corrects each grade, and the admin (the data scientist) manages
users, patient codes and slides. Patients are pseudonym codes, never names.

The backend also serves the web page, so you can open http://localhost:8000 and it
takes you to the page. Open it that way: the page loads its scripts as modules, which browsers
block when the HTML file is opened directly from disk.

### Sharing it for a demo (free)

Run the backend as above, then in a second terminal:

    winget install --id Cloudflare.cloudflared
    cloudflared tunnel --url http://localhost:8000

It prints a `https://....trycloudflare.com` address. Send that one link; it opens the
same page for anyone. The address changes each time, there is no uptime guarantee, and
your computer has to stay on. Press Ctrl+C in that terminal to close it. Use a strong
admin password (`CERVIGRADE_ADMIN_PASSWORD`) and only public dataset images while it
is open, because Cloudflare carries the traffic.

Records are saved in `app_data/` at the repo root (a SQLite database plus the
uploaded images, not tracked by git). Delete that folder to start fresh.

Useful settings (environment variables): `CERVIGRADE_MODEL` (a CNN weights file other
than `models/efficientnetb0_cric_retrained.keras`), `CERVIGRADE_DETECTOR` (a detector file other than the one above),
`CERVIGRADE_DET_CONF` (0.25) and `CERVIGRADE_CNN_SURE` (0.9), `CERVIGRADE_ADMIN_PASSWORD` (choose
the first admin password instead of a random one), `CERVIGRADE_EMAIL_DOMAINS` (allowed email domains, comma
separated, default `alustudent.com`; `*` turns the rule off), `CERVIGRADE_ADMIN_EMAIL`, `CERVIGRADE_DATA` (move the
data folder).

If you are locked out or want demo accounts, run from `src/app/backend`:

    python manage.py list-users
    python manage.py reset-password admin@alustudent.com "a new password"
    python manage.py seed-demo

Tests for the email rule (no model weights needed): `cd src/app/backend && python -m pytest tests -q`.
