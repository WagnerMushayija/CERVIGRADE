# Experiments log

Every experiment that was run for CerviGrade, in one place: what was asked, how it was set up, what came out, and what was decided. Notebook names are the files in `notebooks/`.

Reading guide. "Test set" means the 60 CRIC test slides (1,723 expert-marked cells). All splits are by source slide. Scores are means over three seeds unless the row says otherwise. Rows marked **TO FILL** are experiments that were run but whose numbers are not written down anywhere I could read, so copy them from the notebook output before the defense.

## Notes for the defense

- The detector alone is a "something serious" alarm. It finds cells but cannot grade them reliably, so the CNN does the grading.
- On new data (Mendeley) the pipeline fails: only 1 of 40 photos got the exact grade, and no healthy photo was kept healthy. Say so first, before anyone asks.
- When two rows give different "found" numbers (rows 9 and 11), the cause is strict versus loose matching. Quote one and name it.
